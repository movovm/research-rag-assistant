# Project Evidence Boundary

## Source-aligned project facts

- 场景：课题组项目资料、研发文档、技术报告、规范与新人培训材料的集中检索
- 设计：文档解析、语义分块、Embedding、混合检索、Query Rewrite、短期/长期记忆、证据约束回答
- 技术方向：Spring Boot、LangChain4j、Pinecone、Redis、BM25、SSE、百炼 Embedding 与 Qwen
- AI 协作：AI 辅助单元测试、Git Diff Code Review、项目上下文文档维护

## Newly implemented in the public portfolio

- 无凭据可运行的本地检索和回答适配器
- 文档上传工作台、检索调试页、证据分数 Trace、长期记忆管理界面
- Pinecone / DashScope / Redis Cloud adapters
- 单元测试、CI、脱敏配置、架构与演示文档

这些新增内容是为了把项目设计变成可审查作品，不反向声称它们曾在原团队生产环境上线。

## Excluded claims

- 不提供虚构的公网 Demo 地址
- 不声称本仓库处理过真实团队私有文档
- 不把本地 Feature Hashing 称为语义大模型
- 不声称 RAG 可以完全消除幻觉
- 不把项目介绍材料中的模板、面试话术或“假设已实现”段落作为历史交付证据
