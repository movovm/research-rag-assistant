# 科研资料知识库 RAG 设计

## 文档入库

系统使用 Apache Tika 解析 PDF、Word、Markdown 和纯文本。文档携带文档类型、所属项目和来源等元数据。语义分块先按段落切分，再根据相邻段落向量相似度合并，避免固定字符切分破坏完整语义。每个文本块同时写入关键词索引和向量索引。

## 查询重写

多轮对话中的“这个项目”“该方案”等表达依赖历史上下文。系统先读取短期记忆，把最近一轮明确问题与当前追问合并为独立查询，再用于检索。原始问题仍保留在最终 Prompt 中，防止改写偏离用户意图。

## 混合检索

BM25 擅长匹配 Redis、JVM、错误码等精确术语，稠密向量擅长匹配意思相近但字面不同的表达。系统分别召回候选文本块，对两路分数归一化后按权重融合，默认稠密检索权重为 0.58，最后返回 Top 5 证据。开发环境提供只返回召回片段和分数的调试接口，用于区分检索问题与生成问题。

## 记忆策略

短期记忆按会话保存最近消息，超过字符预算后将较早内容压缩为摘要，并保留最新一半对话。长期记忆只允许用户主动录入偏好或身份信息，内容向量化后按语义相似度召回，避免模型擅自写入不可靠记忆。
